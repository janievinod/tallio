    Frequently asked

    Do I need a wallet to vote?

    Yes, a browser wallet such as MetaMask. There is no sign-up or password. You can browse polls and results without one.

    Which network does Tallio use?

    Ethereum Sepolia, a test network. Test ETH has no real value.

    Are votes anonymous?

    No. Votes are tied to wallet addresses. Addresses are pseudonymous, but anyone can see which address voted for what.

    Are there gas fees?

    Voting is a transaction, so it needs a tiny amount of free Sepolia ETH from a faucet.

    How can I trust the results?

    Every vote is a public transaction on the blockchain, and the numbers you see are read straight from the contract. Nobody can edit them.

    What happens when a poll ends?

    Voting closes at the deadline, or sooner if the admin ends it. Results are then final.

    Is the contract controlled by an admin?

    The admin wallet can create polls and end them early. It cannot add, change or remove votes.
